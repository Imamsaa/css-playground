# Google Sheets integration

This folder contains the Google Apps Script endpoint for CSS Playground submissions.

## Data collected

The sheet stores only these three columns:

1. `Nama`
2. `Tugas`
3. `Waktu Pengumpulan`

The student's CSS source code, score, browser storage, and other profile data are not sent to the sheet. The timestamp is generated by Apps Script and uses the `Asia/Jakarta` timezone.

## 1. Create the spreadsheet

1. Open [Google Apps Script](https://script.google.com/).
2. Create a new project, for example `CSS Playground Submission`.
3. Copy the complete contents of `Code.gs` from this folder into the Apps Script editor.
4. Save the project.
5. Select the function `setup` and click **Run**.
6. Grant the requested Google Sheets permissions.
7. Open **Execution log**. The generated spreadsheet URL is printed there.

The `setup()` function creates the spreadsheet and the `Pengumpulan` tab automatically. Running it again reuses the same spreadsheet.

## 2. Deploy as a web app

1. In Apps Script, click **Deploy → New deployment**.
2. Select type **Web app**.
3. Set **Execute as** to **Me**.
4. Set **Who has access** to **Anyone** so students can submit without signing in.
5. Click **Deploy** and authorize if requested.
6. Copy the web app URL. It should end with `/exec`.

The endpoint is public so students can submit without a Google account. Anyone who obtains this URL can attempt to submit data. For a controlled exam or higher-trust deployment, add student authentication or a server-validated class access code.

## 3. Configure CSS Playground

In the repository's `index.html`, find:

```js
const GOOGLE_SHEETS_WEB_APP_URL = 'PASTE_APPS_SCRIPT_WEB_APP_URL_HERE';
```

Replace the placeholder with the deployed web app URL, for example:

```js
const GOOGLE_SHEETS_WEB_APP_URL = 'https://script.google.com/macros/s/DEPLOYMENT_ID/exec';
```

Commit the change to `main`, then reload CSS Playground.

## 4. Test

1. Open the deployed CSS Playground.
2. Choose any task and click **Kirim Jawaban**.
3. Enter a student name and submit.
4. Confirm that a new row appears in the `Pengumpulan` tab.

The browser sends a small `text/plain` POST to avoid a CORS preflight, then checks a short-lived Apps Script receipt using JSONP. The receipt ID is stored only in Apps Script cache and is not included as a spreadsheet column.

If the browser reports that the submission could not be confirmed, check the Apps Script **Executions** page and the Google Sheet before asking the student to retry. A network interruption can occur after the server has already appended the row.

## 5. Deploy updates

After changing `Code.gs`, use **Deploy → Manage deployments → Edit** and select **New version**. The web app URL normally remains the same when editing an existing deployment.

## Privacy and limitations

- The sheet contains exactly the three requested data fields.
- The submission does not include CSS code, scores, task answers, or local progress.
- The server generates the submission time.
- The endpoint is public and is not an identity-verification mechanism. A name typed by a student is self-reported.
