# CSS Quest — Coding Playground

Playground interaktif untuk latihan CSS Selector, `color`, dan `background` untuk siswa ICT Class.

## Fitur
- 9 tugas bertingkat
- Editor CSS dengan live preview
- Pengecekan otomatis berdasarkan selector dan computed style
- Penyimpanan kode dan progres pada browser siswa
- Tautan tugas melalui parameter URL `?task=<id>`

## Menjalankan
Buka `index.html` di browser atau aktifkan GitHub Pages dari Settings → Pages, pilih branch `main` dan folder `/ (root)`.

Catatan: progres disimpan di browser lokal. Nilai tidak dikirim ke server atau dashboard guru.
