# CSS Quest — Coding Playground

Playground latihan CSS satu file. Tidak membutuhkan Node.js, React, library eksternal, atau koneksi internet.

## Menjalankan
1. Buka `index.html` dengan browser modern (Chrome, Edge, atau Firefox).
2. Pilih tugas di panel kiri.
3. Tulis kode CSS di editor. Preview diperbarui otomatis.
4. Tekan **Periksa Jawaban** untuk mengecek kriteria tugas.
5. Gunakan **Bagikan tugas** setelah aplikasi dipublikasikan melalui URL web.

## Publikasi di GitHub Pages
1. Buat repository GitHub.
2. Unggah `index.html` ke folder utama repository.
3. Buka **Settings → Pages** dan pilih sumber publikasi dari branch utama dan folder root.
4. Setelah URL GitHub Pages aktif, bagikan URL tersebut kepada siswa. Untuk membuka tugas tertentu, tombol **Bagikan tugas** membuat URL dengan parameter tugas yang sedang dipilih.

## Catatan
- Ada 9 tugas tentang selector elemen, class, ID, selector gabungan/turunan, color, background-color, background, dan gradient.
- Kode dan progres disimpan di browser/perangkat yang digunakan siswa.
- Penilaian belum dikirim ke dashboard guru atau spreadsheet. Untuk mengumpulkan nilai dari banyak siswa, diperlukan backend tambahan (misalnya Google Sheets + Apps Script atau Firebase).
